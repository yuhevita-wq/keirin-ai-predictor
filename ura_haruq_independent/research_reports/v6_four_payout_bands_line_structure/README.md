## 特定した出走前のレース構造
- **7車のライン2-2-2-1**：2026年該当1,092R。1万〜3万円決着は26.374%（全7車19.343%）、3万〜5万円決着は6.410%（全7車4.633%）。2024・2025も同方向。F1/F2内比較でも傾向が残る。
- **9車**：2026年5万〜10万円決着7.073%（7車3.487%）。車数とグレードの交絡に注意。
- **予測上位3選手が全員別ライン**：2026年3千〜1万円発生38.240%（LOW全体30.901%）、1万〜3万円23.109%（同19.986%）。
- 決着後の構造として「1〜3着が全員別ライン」の2026年構成比は各配当帯で12.291%、28.145%、36.709%、40.610%。これは出走前には分からないため、購入条件には使わない。

ライン所属が不明・全員単騎のような疑わしい履歴値は別区分扱い。元44特徴量に事後情報がないかの全面監査は未完。

**結論：配当帯別の予測順位型とレース構造の関係は学習できたが、今回の16型は購入方式としては不合格。将来利益の証明ではない。**
