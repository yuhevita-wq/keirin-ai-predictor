# 裏ハルキューV7｜第1工程：型の大量生産

**元ハルキューには一切変更なし。** 裏ハルキュー専用ブランチでの研究記録。

## 今回の結果（2026-10-24）

ユーザー指定の研究順序は **大量生産 → 検証 → 削る**。
本工程は**大量生産のみ**。確定着順、的中、払戻、回収率で選別していない。

- 予測順位を7分割した各着順について、連続・非連続を含む空でない127種類の順位集合を許可
- 候補数は 127³ = **2,048,383**
- 7/8/9車のどの条件でも3人を異なる車番として配置できない2,027件のみ論理的に除外
- **成立しうる順位型：2,046,356件**
- 出走表の3選手のライン所属関係を5分類（全員同線 AAA、12同線 AAB、13同線 ABA、23同線 ABB、全員異線 ABC）
- **順位型 × ライン関係 = 10,231,780件** の識別可能なルールを物理的にCSV.gzで列挙した。
- 別途「1着が自力／番手／3番手／単騎」などの役割条件、出走時のライン構成で型の発動を制御可能。これらの追加バリエーションは上の10,231,780件には含めない。
- **型数上限を設定していない。** 今回の件数は採用枠ではなく、選んだ生成文法を網羅した数。

2024年LOW 15,915レースの独立予測順位と、保存済み出走表相当データのライン配置だけを読み込んだ。実結果・配当は型生成に使っていない。ラインのグループ名が空の場合、類推で補わない。

主要ライン構成：

- 3-3-1：2,600レース

実レース20ケースについて、複数の型から実際に成立する車番の3連単組を生成して形式確認した。

## 厳密に区別すべきこと

10,231,780件は**構文上区別できる型ルール数**であり、あらゆる特定のレースで買い目が発生する型数ではない。同じレースで買い目が重複する型、線の組合せが存在しない型、購入点数が膨らむ型も混在している。実用性・収支は**未評価**。役割・ライン履歴の出走前時点での可用性について、さらなる監査が必要。

次工程（まだ実施しない）：型を出走前ライン構成別に展開 → 2024/2025/2026の時系列で収益・重複・増分価値を検証 → **型数をあらかじめ制限せず**安定しないものを削る。4つの配当帯（3千〜1万、1万〜3万、3万〜5万、5万〜10万円）は後続検証のラベルとして使い、型生成時の絞り込みには使わない。
