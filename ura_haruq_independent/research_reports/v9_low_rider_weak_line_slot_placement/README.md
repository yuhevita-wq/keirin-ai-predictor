# 裏ハルキューV9：予測下位・弱ラインを何着に置くべきか

**2026-10-24 研究専用。元ハルキューの固定モデル・運用ブランチ・Web予測・買い目・配分は一切変更しない。** 本研究結果の購入採用なし。

## データ
V8の結果と出走表ライン情報、独立予測AIの順位を結合。LOW 42,423R（2024 15,915／2025 15,450／2026年1〜9月11,058）。低評価＝予測順位5位以下、最弱ライン＝所属選手の予測スコアの平均が最小のライン。**公式競走得点による最弱ラインではない**。

## 着順配置の発見

予測5位以下の選手1人当たり、2024〜26年合算で、自力は1着約5.0%／2着7.0%／3着9.1%、番手は約4.1%／8.9%／10.5%、3番手は約1.6%／5.5%／16.0%。ただし単独の入着率は車券ROIではない。

予測下位・弱ラインの中の順位・役割×レース構成×相手候補×着順×購入した券のライン関係の各要素を組み合わせ、4,050の成立したテンプレートについて実際の3連単購入点数（各100円、重複は除外）、的中、実払戻を3年間で検証。4つの配当帯も的中・払戻別に集計した。買い目生成コードとは独立の検算で6ケース×3年間=18ケースの点数・的中・払戻が完全一致。

## 発見した強い候補：LOW・7車2-2-2-1「予測上位同線 1・2着／予測下位別線 3着」

- 出走前ライン形が**2-2-2-1**でLOW。
- 予測上位3人に同一ラインの2人がいれば、その2人を**1・2着の両方の順序**に配置。
- **予測5位・6位・7位**のうち、上の2人と異なるラインの選手を3着に配置。
- 1点100円。通常は**6点**。該当する予測上位の同ラインペアがなければ買わない。

ユーザー指定の4配当帯 **3,000円以上〜100,000円未満** に含まれる的中払戻だけで投資全額を回収した割合は**2024年150.88%、2025年129.68%、2026年140.50%**。10万円以上の当たりに依存しない。月別で全払戻ROI100%超：2024年12/12月、2025年11/12月、2026年8/9月。

- 別条件「低評価かつ**最弱ライン**のみ3着」：ROI 191.0%／147.9%／138.1%。
- 別条件「最弱ライン内の予測順位最上位の選手を3着」：163.9%／155.4%／196.7%。
- 別条件「予測5位以下の単騎を3着」：206.0%／196.9%／164.4%。
- 各条件は買い目が重なるため利益を足し算してはいけない。
- 同じ「予測上位の同ライン1・2着→予測5位以下3着」を**3-2-2**構成に移すとROIは**68.3%／74.6%／73.6%**。レース構造による違いが大きい。

## 注意：研究段階の発見であり購入採用ではない

- 事後の多数探索（約4050テンプレート）による選別バイアスがある。2026年は以前の研究でも何度も確認しており、純粋な初見データではない。
- 各年の独立学習AIの予測は対象年のレースを学習していないが、44特徴量の全値が真に出走前取得可能だったかの厳密な時点監査は未完。
- 確定払戻による事後評価。締切前のオッズ、オッズ変動、購入執行可否は別途未検証。
- 今後、2026結果を見て型を変え、同年を未使用検証と呼んではいけない。
- **元ハルキューには絶対に触らない。**
