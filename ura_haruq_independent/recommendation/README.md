# 裏ハル V1：LOW4区間「おすすめ度」表示レイヤー

**2026-10-24 初版。固定済み裏ハルV1（`frozen/ura-haru-v1-20261024`、commit `7adf108f33a16c5043e79b2f6cf737d9bc397095`）は変更しない。** 本家ハルキュー、`master`、公開済み `docs/index.html` にも一切変更しない。

## 何を追加したか

ユーザー採用済みV1の「発走前 LOW 7車2-2-2-1 / 上位同ライン2人の1・2着両順序 / 予測5〜7位かつ別ラインを3着」のフォーメーションを**元の固定Pythonコードで計算し、その結果におすすめ度メタデータだけを追加表示**する。LOWの4帯に、下記の過去実績に基づく人間可読の比較ラベルを付ける。

| 予測上位1-2位スコア差（LOW） | おすすめ度 | 2024/25/26の指定3千〜10万円未満の払戻のみROI | 2024/25/26の黒字月数 |
|---|---|---|---|
| 0.00以上0.25未満 | ★★★☆☆ 標準 | 201.62 / 101.09 / 126.44% | 12/12, 6/12, 6/9 |
| 0.25以上0.50未満 | ★★★★★ 最優先 | 113.75 / 156.87 / 206.97% | 10/12, 9/12, 8/9 |
| 0.50以上0.75未満 | ★★★★☆ 優先 | 115.17 / 149.61 / 129.65% | 6/12, 9/12, 7/9 |
| 0.75以上1.00未満 | ★★☆☆☆ 注意 | 155.74 / 115.38 / **80.03%** | 7/12, 8/12, 4/9 |

各年の総合ROIや発動レースの的中率は `low_quarter_advisory.py` の履歴データに併記。2026年は**1〜9月のみ**。0.75〜1帯では2026年に26万8,200円の高額的中が含まれるため、総合ROI341.00%よりも「指定配当帯に限定した80.03%」の弱さを優先して注意表示する。

`★★★★★`の意味は**将来の勝率や期待値ではない**。統計的に較正されたランキングではなく、既知の過去検証結果による表示用の相対評価。2026年成績も以前の研究で参照されているので完全な初見検証ではない。

## 実行例：ユーザーの出走前データを読み込み、新しいJSONへ付加

対象は**独立予測モデルの**順位・スコア差・発走前のライン所属を利用すること。元ハルキューのスコアを転用してはならない。

```bash
cat > /tmp/ura_sample.json <<'JSON'
{
  "race_id": "example",
  "score_gap": 0.37,
  "predicted_bikes_by_rank": "3-5-1-2-6-7-4",
  "line_groups_by_bike": "3:A;5:A;1:B;2:B;6:C;7:C;4:D"
}
JSON
python -m ura_haruq_independent.recommendation.low_quarter_advisory \
  --input /tmp/ura_sample.json --output /tmp/ura_sample_recommended.json
python -m unittest ura_haruq_independent.recommendation.test_low_quarter_advisory -v
```

出力は`original_input`と`ura_haru_v1_display`の2領域。出力の`tickets`は凍結されたV1から得る。別レイヤーの`recommendation`が表示情報。`status=v1_not_applicable`の場合には、星評価は**null（つけない）**で購入点数0。

JSON出力は別パスに限り、元入力へ上書きしない。自動投票・金額変更・不参加化・Web本番への公開はしない。

## 固定すべき境界と品質保証

- 区間は左閉右開。`0.25→★★★★★`、`0.50→★★★★☆`、`0.75→★★☆☆☆`、`1.00→対象外`。
- 上位に同一ライン2人がいない場合、7車/2-2-2-1以外、情報不足の場合、星評価を捏造しない。
- 凍結V1本体をSHA-256照合。テストで買い目と点数は凍結コード出力と一致し、元入力の`bets`・`total_yen`は変更しない。

**公開の扱い**：このファイルは裏ハル研究ブランチにある実装。元ハルキューWebへ合流させていない。将来的に裏ハル専用公開画面を作る場合も、別指示を受けるまで本家への統合は行わない。
