## 停止の仕組み
protection/haruq-lock.json は、原本と運用コード、依存する特徴量・モデル読込・出走表処理、購入方針、Web表示と実行ワークフローのSHA256を固定する。
予測前、Web出力前、Actions開始時に照合し、不一致・欠落・リンク置換で例外終了する。モデルファイルは従来のSHA256照合を継続する。
設定と特徴量はActionsが原作者スナップショットを一時配置するため、ソース状態と実行状態を別々に検証する。任意の変更は許可しない。
Web出力前には、スコア差・順位・HIGH限定・フォーメーション・点数・金額も照合する。
解除フラグ、環境変数による回避、台帳の自動更新コマンドは設けない。

## 明示承認が必要な変更
変更箇所と差分、影響を提示し、ユーザーがその内容を明示承認した場合のみ別作業で保護基準を更新する。
「改善」「再実行」「ギリギリ合格」を、モデルや全レースの基準変更に拡張解釈しない。

## 権限上の限界
これは無断変更を検出して実行を止めるガード。GitHubの同じ書き込み権限でガードやワークフローまで書き換えれば回避され得る。
この時点でGitHub rulesets APIの一覧は空。管理権限でのルール作成APIはこの接続に公開されていないため、所有者による外部の権限制限は未設定。
完全な強制には、所有者のみが解除できるブランチ保護／ルールセット、保護ファイルの所有者レビュー、AI接続の更新権限制限をGitHub側で設定する必要がある。所有者の権限まで奪う仕組みとは説明しない。
