# 裏ハルキュー V1 — 専用Web（表ハルキューとは完全分離）

## 実装した画面

- `index.html` — 表ハルキューの見た目を踏襲したスマホ対応画面。ホーム、本日のおすすめ、日付指定、開催場・レース一覧、レース詳細、収支・検証。
- `results/index.json` — **裏ハル独自の**レース索引。新しい予測が公開されるまで空。
- `results/<12桁race_id>.json` — 2026独立予測AIの順位・スコア、発走前ライン、固定V1の買い目、LOW4帯のおすすめ度。ネットワークから既存「表ハル」のSupabase予測テーブルを一切取得しない。
- `ura_haruq_independent/web/live_predict.py` — 44特徴量を継承した**独立学習モデル**により出走前情報からスコアを算出。
- `ura_haruq_independent/web/publish.py` — 発表データを厳密検証し `docs/ura-haru/results/` のみに出力。
- `.github/workflows/ura-haru-live-web.yml` — GitHub Actionsで独立モデルの暗号化履歴・予測・Webデータ公開を実行する。

## 固定版とおすすめ度

- 裏ハルV1凍結ブランチ：`frozen/ura-haru-v1-20261024`、commit `7adf108f33a16c5043e79b2f6cf737d9bc397095`
- LOW 0〜1未満、7車、2-2-2-1、上位同ライン2人を1〜2着両順序／別ライン予測5〜7位を3着（通常6点）。
- おすすめ度は 0.00〜0.25 ★★★☆☆、0.25〜0.50 ★★★★★、0.50〜0.75 ★★★★☆、0.75〜1.00 ★★☆☆☆。
- 星は**表示だけ**。買い目の削除、配分変更、別モデル化、元ハルキュー本体への変更をしない。
- 2026年独立モデルは2023〜2025データから学習した研究モデル。**本番向けの発走前特徴量時点監査は未完**。過去の高ROIが将来の利益を保証しない。

## 独立予測の配信状況

Webの初期索引は0レース。Github Actionsで成功したイベントの独立予測のみを追加する。予想が無い日は「未公開」と表示し、**表ハルキューの予想を転載したり、適当に買い目を補ったりしない**。

## 公開について（重要）

2026-10-24時点、リポジトリのGitHub APIで `has_pages=false` を確認。したがって、このファイル群をコミットしただけではGitHub Pagesの公開URLはまだ有効ではない。**表ハルの公開サイト／設定を変更しないため、Pagesの設定を無断変更しない。**

別の静的ホスティング（Vercel等）を接続する場合、独立ブランチ `ura-haruq/independent-train-20261024` の `docs/ura-haru` をサイトルートとして指定すること。現在の `index.html` は GitHub 上の独立ブランチにある予測JSONだけを取得する。公開環境のキャッシュ・CORSの動作はデプロイ後に実測確認する必要がある。

現時点で確認済み：専用フロントエンドのJavaScript構文チェック、Pythonの固定ルール同一性検算、JSONのフォーマットと分離検査、境界値テスト。新しい独立予測の稼働は `Ura Haru V1 - Independent Live Web` workflow で独立に検証する。

## 表ハルの不変性

`docs/index.html`、`docs/haruq/`、`scripts/flagship_live_predict.py`、`master`、表ハル固定モデル、表ハル凍結ブランチには一切書き込まない。両方のWebでレースIDが同じでも、推定スコア・車券・おすすめ度・収支を混ぜない。
